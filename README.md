# 記易創新 MemGenius Innovation 官網樣板

一個不需建置工具的單頁靜態官網，可直接部署到 GitHub Pages。

## 本機預覽

```bash
python3 -m http.server 4173 --directory memgenius-company-site
```

接著開啟 `http://localhost:4173`。

## 內容

- 公司與品牌定位
- 記憶策略三原則
- 可操作的 20 秒記憶實驗
- 四種 MemGenius 方法
- Jerome Kuo 創辦人故事
- 免費體驗、90 分鐘工作坊及機構合作方案
- Email 聯絡入口

## 上線前可替換資料

- 將 Jerome 的 `JK` 視覺占位換成已授權的人物照片。
- 加上 LINE 官方帳號連結與 QR code。
- 補入第一場活動日期、地點、票價及報名頁。
- 公司完成登記後，補上正式公司全名、統編、地址及隱私權政策。
